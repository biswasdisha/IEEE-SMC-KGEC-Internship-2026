About the Chest X-ray Pneumonia Detection Project

This project demonstrates a complete AI-powered web application that uses a trained deep learning model to classify chest X-ray images as either normal or pneumonia-affected.

Project Description

The system uses a ResNet50-based convolutional neural network trained on chest X-ray data to support rapid screening and assist medical professionals with decision support.

Dataset

The classification model is trained on publicly available chest X-ray datasets containing both normal and pneumonia cases.

Technology Used

Flask powers the backend, TensorFlow and Keras handle deep learning inference, and Bootstrap 5 provides a responsive frontend experience.

Deep Learning Models

ResNet50, TensorFlow, Flask, and NumPy work together to preprocess the image and deliver predictions in real time.

Developer

This web application was developed as a B.Tech final year project to showcase AI-driven medical image analysis in a practical deployment.
